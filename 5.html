From statistics to a finite sum

The Regression Problem and Empirical Risk

Regression targets an expectation that we cannot compute directly. We replace it with a sample average we can.

Statistical target

The regression function is the conditional mean of Y given X. It minimizes the mean squared error:

m(x) = 𝔼[ Y | X = x ] m(·) = arg minf 𝔼[ (f(X) − Y)² ]
Numerical substitute

The expectation is unknown. We only have samples (Xᵢ, Yᵢ), for i = 1, …, N, so we replace 𝔼 by a sample average:

J(f) = 1N ∑i=1N ( f(Xᵢ) − Yᵢ )²
Key pointThe expectation is replaced by a quadrature (Monte Carlo) approximation. This introduces a statistical error that is controlled by the sample size N.

Two regimes

Linear Model vs Neural Network

The shape of the loss depends on how the model depends on θ. That single fact decides how hard the problem is.

Comparison
ModelDependence on θLoss J(θ)
Linear regressionfθ(x) = θᵀxConvex (quadratic)
Neural networkNonlinear in θNon-convex

For the linear model, the classical solution is available in closed form through the normal equations:

AᵀA θ = Aᵀy
Linear case in matrix form

Let A be the design matrix (rows Xᵢᵀ) and y the vector of targets:

J(θ) = 1N ‖Aθ − y‖2² ∇J(θ) = 2N Aᵀ(Aθ − y) ∇²J(θ) = 2N AᵀA (constant)
Key pointConvexity gives a unique minimizer and a closed-form solution. Both are lost for neural networks.

Part 2 · Gradient descent as a numerical method1 / 3
The iteration

Steepest Descent for the Loss Function

Starting from an initial guess, each step moves against the gradient, the direction in which the loss increases fastest.

Update rule

We want min J(θ). Nonlinear and non-convex, so we iterate:

θk+1 = θk − αk ∇J(θk), k = 0, 1, 2, …
  • ∇J(θk) points toward steepest ascent.
  • −∇J(θk) points toward steepest descent.
  • αₖ > 0 is the step size, also called the learning rate.
Stopping criteria
  • Small gradient: ‖∇J(θk)‖ < ε
  • Small step: ‖θk+1 − θk‖ < ε
  • Iteration budget: k > Kmax
Key pointThis is steepest descent applied to a very high-dimensional objective. Two questions remain: how to compute ∇J cheaply, and how non-convexity changes the guarantees.

Part 2 · Gradient descent as a numerical method2 / 3
Cost of the gradient

The Gradient Must Be Cheap

With p in the millions, computing each partial derivative separately is not an option.

Naive approach · finite differences
∂J/∂θj ≈ ( J(θ + h eⱼ) − J(θ) ) / h
  • One full evaluation of J per coordinate.
  • Cost: O(p) evaluations per gradient step.
  • For p = 10⁶, that is a million forward passes per iteration. Infeasible.
Backpropagation

All p partial derivatives are obtained in one backward pass, at a cost comparable to one evaluation of J:

Cost of ∇J ≈ Cost of J (a constant factor)
Key pointBackpropagation is not a new mathematical idea. It is the chain rule, organized for computational efficiency. That is what makes gradient descent feasible at scale.

Part 2 · Gradient descent as a numerical method3 / 3
Numerical levers

The Two Levers: Step Size and Jacobians

Three things govern whether gradient descent behaves well: the step size, the conditioning of the problem, and the depth of the network.

1 · Step size α

A stability parameter, not just a tuning knob.

  • Too small: convergence is extremely slow.
  • Too large: the iteration oscillates or diverges.

For smooth J with Lipschitz constant L of the gradient:

0 < α < 2 / L
2 · Conditioning

The convergence rate depends on the condition number of the Hessian:

κ = λmax / λmin

A large κ means slow convergence, the same phenomenon as in linear solvers.

3 · Vanishing and exploding gradients

δ(l) involves repeated multiplication by W(l+1) and σ′. The magnitude can therefore decay or grow exponentially with depth:

‖δ(l)‖ ∼ ∏j>l ‖W(j)‖ · ‖σ′‖
Key pointGradient descent is simple to write, but its behavior is governed by conditioning and stability. These are the same principles as in classical numerical analysis, now applied to a non-convex, high-dimensional problem.

Part 3 · Convergence1 / 2
The basic guarantee

The Loss Keeps Going Down

Under one assumption, a smooth loss, a sufficiently small step always decreases J. The step size must respect the curvature.

Assumption · L-smoothness

Run the iteration with a fixed step:

θk+1 = θk − α ∇J(θk)

There is a constant L > 0 such that:

‖∇J(θ) − ∇J(θ′)‖ ≤ L ‖θ − θ′‖

In plain words, the gradient does not change too fast. L measures how strongly the loss curves.

Descent lemma
J(θk+1) ≤ J(θk) − α ( 1 − Lα/2 ) ‖∇J(θk)‖²
  • If 0 < α < 2/L, the bracketed term is positive.
  • The loss then strictly decreases at every step.
  • Too large a step, and the loss can increase instead.

This is the same stability condition known from numerical methods: the step is limited by the curvature of the problem.

Key pointConvergence is not automatic. It requires a small enough step, and the safe range is set by the smoothness constant L.

Part 3 · Convergence2 / 2
Speed and guarantees

Convex vs Non-Convex

With a safe step size, gradient descent always drives the gradient to zero. The open question is what kind of flat point it reaches.

‖∇J(θk)‖ → 0

So the iteration always reaches a stationary point, a place where the loss is flat. Whether that point is the global minimum depends on the shape of the loss.

Case 1 · Convex loss (linear regression)

Every stationary point is the global minimum, so convergence is complete.

  • κ ≈ 1 (well-conditioned): fast convergence.
  • κ ≫ 1 (ill-conditioned): very slow, since the iteration crawls along flat directions.

Iterations needed for accuracy ε:

k ∼ κ · log(1/ε)
Case 2 · Non-convex loss (neural networks)

A stationary point can be a local minimum, a maximum, or a saddle point. Gradient descent does not guarantee the global minimum.

Picture walking downhill in fog. You stop when the ground is flat, but that spot may be a valley floor, a ledge, or a saddle. From the slope alone, you cannot tell which.

Key pointIn both cases gradient descent reaches a stationary point. Only in the convex case is that point guaranteed to be the global minimum. In both cases, speed is governed by κ.

Part 4 · Effect on neural-network regression1 / 2
The algorithm selects the solution

Many Functions Fit the Data

Several parameter vectors can reach a small training loss while defining different regression functions. The iteration decides which one we get.

Three numerical choices
  • Initialization θ₀ selects the basin of attraction we enter. This is what the three balls in the 3D lab show.
  • Step size α: large steps overshoot and oscillate; small steps move slowly.
  • Stopping index K: we stop at θK, not at the true minimizer.
Training loss ≈ small for many θ, but fθ differs
A clean case · linear model, θ₀ = 0

If A has more columns than rows, the minimizers are not unique. Gradient descent converges to the one with the smallest norm:

θ* = Aᵀ(AAᵀ)−1y, ‖θ*‖2 = min { ‖θ‖2 : Aθ = y }

This is the simplest example of implicit bias: among all exact solutions, gradient descent prefers the one of small norm.

Key pointGradient descent is not a neutral solver. Its path and stopping point are part of the model. The triple (θ₀, α, K) selects the regression function we actually learn.

Part 4 · Effect on neural-network regression2 / 2
Generalization

The Numerical Choices Control Generalization

Training error and test error follow different paths as the iteration proceeds. Stopping early is a form of regularization.

Two errors as K grows
J(θK) training error 𝔼[ (fθK(X) − Y)² ] test error
  • Training error always decreases.
  • Test error decreases, then increases. The rise is overfitting.
Early stopping as implicit regularization

Stopping at a moderate K keeps θK close to θ₀, with small norm. The function fθK is then smoother and fits the noise less.

K ⟷ regularization strength

In the linear case, early stopping of gradient descent closely corresponds to ridge (shrinkage) regularization.

Key pointStep size, initialization, and the number of iterations are not implementation details. They control the smoothness and norm of the learned function, and therefore its generalization.

Part 5 · SummaryWhat we have seen
Summary

Gradient Descent Through the Lens of Numerical Analysis

1 · Regression as a numerical problem
minθ J(θ) = 1N ∑ ( fθ(Xᵢ) − Yᵢ )²
A nonlinear least-squares problem: convex for linear models, non-convex for neural networks.
2 · The method
θk+1 = θk − αk ∇J(θk)
The gradient comes from backpropagation, at a cost of about one evaluation of J, versus O(p) for finite differences.
3 · Convergence
  • L-smoothness gives a safe step, 0 < α < 2/L.
  • Convex: global minimum, with k ∼ κ · log(1/ε).
  • Non-convex: a stationary point, not necessarily the global minimum.
4 · Effect on the learned function
The choices (θ₀, α, K) select which function fθ is learned. The algorithm carries an implicit bias toward smooth, low-norm solutions, and early stopping acts as regularization.
In one lineGradient descent is steepest descent applied to a high-dimensional, non-convex objective. Its numerical behavior, namely conditioning, stability and stopping, directly shapes the regression function it produces.
